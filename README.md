# JD Builds Clients

Standalone client constellation for `clients.jdbuilds.ca`.

## Commands

```bash
npm install
npm run dev
npm run build
```

## Data Notes

- Active client data reviewed on 2026-05-11.
- HarvestingPro clients use the active Stripe/subscription list supplied during planning, with Hytest Timber Ltd. intentionally excluded.
- Public websites/favicons are used only where the match looked confident.
- Unlinked forestry clients were left without website URLs to avoid attaching directory pages or unrelated companies.
